# Global Printable Watermark Addendum — Learning Is Fun

## Status
Mandatory cross-module addendum for all printable/PDF/question outputs.

## Goal
Ensure every printable document, printable question set, PDF export, receipt/report, exam result sheet, and future print-oriented artifact generated by the ERP carries a default `Learning Is Fun` watermark.

## Scope
Apply to all present and future print/PDF surfaces, including at minimum:

- Learning Planner Exam Results PDFs and printable result sheets.
- Individual Student result PDFs.
- Practice Work printable questions/question sets.
- Practice Work answer/review printouts where printing is supported.
- Fees receipts.
- Fees reports and statements.
- Student/Parent printable financial statements where supported.
- Attendance printable reports where supported.
- Any future printable schedules, reports, certificates, summaries, or exported PDFs.

This addendum does not require adding print functionality to pages that do not currently support it unless another module specification explicitly requires printing/PDF generation.

## Default Watermark
The default text watermark must be exactly:

`Learning Is Fun`

The watermark must be enabled by default for every supported printable/PDF output.

## Presentation Requirements
- Watermark should be subtle and readable without obscuring primary content.
- Prefer a large diagonal or centered low-opacity text watermark behind the document content.
- Repeat on every printed/PDF page where technically practical.
- Keep normal content, tables, questions, answers, signatures, totals, and barcodes/receipt identifiers fully legible.
- Do not place the watermark in a way that changes pagination materially or causes content reflow.
- Do not rely only on a browser background color that may disappear when users disable background graphics.
- Where server-side PDF generation is used, render the watermark into the PDF itself.
- Where browser printing is used, include print-specific CSS that renders the watermark in print media.

## Branding Source
Use the canonical institute/product display name where a shared branding configuration already exists, but the fallback/default watermark text must remain `Learning Is Fun`.

Do not fetch branding from the client when generating authoritative server-side PDFs.

## Question Printing Requirements
Any printable Practice Work/question output must include the watermark by default, including:

- Individual printable questions.
- Practice Set question papers.
- Generated question previews when exported/printed.
- Question Bank selections when printed.

The watermark must never expose answer keys or explanations to Students before submission. It is purely visual branding and must not alter existing answer-security rules.

## Exam Results Requirements
For Learning Planner Exam Results Publishing:

- Administrator full exam-wise result PDF: watermark required.
- Administrator print view: watermark required.
- Individual Student result PDF: watermark required.
- Parent/Student printable result view, if implemented: watermark required.

The watermark must not reveal unpublished result data or bypass existing publication/RLS rules.

## Fees Requirements
- Fee receipt PDF/print: watermark required.
- Fee collection/outstanding report PDF/print: watermark required.
- Student fee statement/ledger print, if supported: watermark required.

The watermark must not interfere with receipt number, amount, payment mode, or audit details.

## Shared Implementation Preference
Prefer a reusable shared print/PDF branding layer rather than duplicating watermark code in each module.

Recommended structure may include shared utilities/components such as:

- `components/print/print-watermark.tsx`
- `lib/print/branding.ts`
- shared PDF helper/layout component

Exact paths should follow the repository architecture after inspection.

## Default and Overrides
- Watermark is ON by default.
- Do not add a user-facing disable toggle unless explicitly requested later.
- Do not allow Students/Parents to disable the watermark.
- Administrator disable/override controls are out of scope unless separately requested.

## Accessibility / Print Quality
- On screen-only views, do not add distracting watermark overlays unless the view is explicitly a print preview.
- In actual print/PDF output, ensure contrast remains low enough to avoid obscuring text but high enough to remain visible.
- Verify grayscale printing remains usable.

## Security
The watermark is branding only. It must not be used as an authorization mechanism, data-integrity marker, or anti-tamper control.

Existing server authorization, RLS, publication status, answer isolation, and financial permissions remain authoritative.

## Verification
For every newly implemented or modified printable/PDF surface, verify:

1. `Learning Is Fun` watermark appears by default.
2. Watermark appears on every page where applicable.
3. Primary content remains readable.
4. No unexpected page overflow/reflow occurs.
5. PDF output contains the watermark even when opened outside the browser.
6. Browser print view contains the watermark when applicable.
7. Question printouts do not expose protected answers.
8. Student/Parent outputs remain scoped to authorized records only.
9. Lint, TypeScript, build, and `git diff --check` pass.

## Compatibility
Do not change business logic, grading, scoring, fee accounting, receipt numbering, Attendance calculations, Planner scheduling, publication status, or RLS behavior solely to implement the watermark.
